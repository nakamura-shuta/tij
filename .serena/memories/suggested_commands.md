# Suggested Commands

- Build: `cargo build`.
- Run locally: `cargo run`.
- Full test suite: `cargo test`.
- Unit tests only: `cargo test --lib`.
- Integration tests only: `cargo test --tests`.
- Snapshot tests: `cargo insta test`.
- Format: `cargo fmt`.
- Lint: `cargo clippy`.
- Project guidance says completion should include formatting and clippy fix where appropriate: see `mem:task_completion`.
- Search files/text with `rg` / `rg --files`.
